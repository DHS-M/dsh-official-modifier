DeepSeek Harness modification layer

DSH Official Modifier

Apply the remote/web-only Harness changes to an existing official DeepSeek Harness checkout without replacing the checkout or touching unrelated plugin work.

Clean worktree required.

The modifier refuses to mix the product patch with uncommitted changes. Commit or stash local work first. Every reachable caller receives host authority in open mode.

Prepare the official checkout

git clone https://github.com/deepseek-ai/deepseek-harness.git "$HOME/deepseek-harness"
cd "$HOME/deepseek-harness"
git checkout b150a551b8d465e31e418e1b2eaf5e79bbb7d28e

Apply the modifier

git clone https://github.com/kenqtade/dsh-official-modifier.git "$HOME/dsh-official-modifier"
BUILD=1 "$HOME/dsh-official-modifier/modify-official.sh" "$HOME/deepseek-harness"

Set BUILD=0 to apply the patch and install dependencies without immediately building. The script is idempotent and verifies whether the patch is already applied.

Run the modified web interface

cd "$HOME/deepseek-harness"
pnpm dsh web --host 0.0.0.0 --open-authority --no-open

Modification matrix

AreaModifier behavior
Core transportAdds explicit open authority across HTTP, WebSocket, shared RPC, and dedicated channels.
Browser authorityPropagates the server authority marker so remote pages use host-backed settings.
Configuration fileReplaces the native desktop handoff with a browser editor over typed settings RPC.
Workspace selectionUses the existing browser filesystem flow for remote directory listing and creation.
DeepSeek providerRemoves the provider and its web-search companion from the active base composition while keeping source packages intact.

Source and reproducibility

The exact change is in patches/open-authority-web-only.patch. The source baseline is pinned in UPSTREAM-COMMIT.txt. If the official project changes enough for the patch not to apply, review the patch manually rather than forcing it over local work.
